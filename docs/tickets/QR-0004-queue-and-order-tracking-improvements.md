## Summary

Static review of all runtime Quadrunner modules at `d00cc32` identified concrete defects and algorithmic inefficiencies—primarily in how `DogNetwork` tracks, ranks, backs off, reconciles, and hands off queued orders, plus secondary edge cases in combat/pack/smoke coordination, trap avoidance, survey invalidation, charge-spot lookup, and per-tick loops.

This ticket records every verified finding with exact file/line evidence, proposed fixes, and acceptance criteria. No gameplay code or runtime benchmarks have been run under this ticket.

## Verified findings

### 1. Queue tracking and order assignment (`Network.cs`, `Work.cs`, `Hose.cs`)

| ID | Class | Finding | Evidence | Impact |

| Q1 | Bug | `AssignAll` stamps `task.retryAt = Now + Tuning.scanInterval` whenever `nearest == null`, even when **zero** capable idle dogs were available to evaluate the task. | Q2 | Algorithm | `AssignAll` assigns strictly one task at a time in `CompareTasks` (`task.id` FIFO) order and evaluates **every** idle dog with `JobFor` + full A* `FindPathNow` with no geometric lower-bound pruning (unlike `Survey.Select`, which already prunes via `distance * step > bestCost`). | [`Network.cs:518-547`](../../Source/Quadrunner/Network.cs#L518-L547), [`Network.cs:992-1062`](../../Source/Quadrunner/Network.cs#L992-L1062), [`Survey.cs:169-200`](../../Source/Quadrunner/Survey.cs#L169-L200) | Within equal-priority tiers (e.g. `Haul`, equal-rank non-bleeding `Rescue`, or solo `Combat`), dogs bypass nearby targets for older distant IDs and crisscross the map; every idle dog runs full A* pathing per queued task even when a nearby dog already found a cheap path. |
| Q3 | Bug | `Reconcile` tracks progress only via `dog.Position`, `CurToilIndex`, and `ticksLeftThisToil`. Stationary jobs using `ToilCompleteMode.Never` (`AttackStatic`, `AttackMelee`, `JobDriver_CleanWithHose`, continuous `Firefighting`) do not change those values, and `TakeOrder`'s `IsContinuation` branch returns early without refreshing `task.progressAt`. | [`Network.cs:708-718`](../../Source/Quadrunner/Network.cs#L708-L718), [`Network.cs:1129-1136`](../../Source/Quadrunner/Network.cs#L1129-L1136), [`Hose.cs:268`](../../Source/Quadrunner/Hose.cs#L268) | Any stationary combat engagement, foaming job, or hose spray lasting longer than `progressTimeout` (2,500 ticks) is falsely terminated via `StopSafely(dog)` and placed into 120-tick backoff mid-action. |
| Q4 | Responsiveness | `TakeOrder` performs immediate job-boundary handoff only for `Fire` (`TakeFireOrder`) and pack combat (`packs.Target`). | Q6 | Queue semantics & scaling | Multi-target `QR_CleanWithHose` / `Clean` jobs assign only the seed `NetworkTask`, leaving sibling patch tasks with `assigneeId == null`. `Hose.PriorityTasks` does not skip reserved filth, re-runs BFS on every tile of sub-threshold (<4 tile) patches, and allocates 5+ collections every 60 ticks. Unhaulable items (full stockpiles) stay in `State.normal` and are probed against every idle worker every 120 ticks with flat backoff. | [`Hose.cs:67-103`](../../Source/Quadrunner/Hose.cs#L67-L103), [`Hose.cs:176-204`](../../Source/Quadrunner/Hose.cs#L176-L204), [`Network.cs:502-504`](../../Source/Quadrunner/Network.cs#L502-L504), [`Network.cs:978-987`](../../Source/Quadrunner/Network.cs#L978-L987) | Reserved hose patch tiles outrank hauling/construction on every refresh and force repeated failed probes; full-stockpile colonies execute `O(Unhaulable × IdleWorkers)` `TryFindBestBetterStoreCellFor` searches every 120 ticks. |

## Proposed approach

Work can be split into three independent, incrementally verifiable slices:

1. **Slice 1 — Correctness fixes (Q1, Q3, C1, C5, S3, S4, minor S5):**
   - Guard `AssignAll`'s `retryAt` backoff on whether at least one capable idle dog was actually evaluated, and break early out of `AssignAll`'s dog loop if `CaptureJob` released the task.
   - Update `Reconcile` / `TakeOrder` progress tracking so stationary active combat (`Stance_Busy.startedTick`), firefighting, and `JobDriver_CleanWithHose` spraying count as progress.
   - Fix `SmokeCoordinator` cluster keying (per connected cluster or local radius count, active fighting T4s only) and clear transient tables in `DogNetwork.ClearAll()`.
   - Validate standability inside `CellInNearestRoom`'s BFS callback, return temporary `Job`s to `JobMaker.ReturnToPool`, cache `Apparel_GasMask` lookup, clear `DamageWorker_TearGas` static fields in `finally`, and inspect the next path node in `Riding.EnteringIndoors`.
2. **Slice 2 — Queue indexing and dispatch algorithm upgrades (Q2, Q4, Q5, Q6, Q7, C2, C3, C4):**
   - Add transient `O(1)` task-dedup indexes on `DogNetwork`, reusable `HashSet<Thing>` for `ThingsPotentiallyNeedingHauling()`, single-pass post-load `NetworkTask.target` resolution, direct `Rescue.IsPatient` check in `Finished()`, and cached `ThingID` in all remaining loops.
   - Add Chebyshev lower-bound pruning in `AssignAll`, nearest-`(dog, task)`-pair matching within equal-priority tiers (keeping strict priority order across tiers and deterministic tie-breaking), and immediate job-boundary handoff in `TakeOrder`.
   - Skip reserved targets in `Hose.PriorityTasks` and `AssignAll`, reuse scratch collections and track visited small components in `Hose.PriorityTasks`, add capped exponential backoff for persistently unassignable tasks, and avoid redundant probes across idle dogs sharing an allowed area on target-side failures.
   - Tighten `PackCombat.CaptureKeeper` capture-feasibility check, avoid piling solo dogs onto pack-focused enemies when unengaged hostiles exist, and validate carry/drop-off trap legs from the pickup cell.
3. **Slice 3 — Late-game colony scaling (S1, S2, S5):**
   - Invalidate `Survey.Geometry` candidates only on affected areas (and build door-adjacent cells from the door list rather than scanning 4 neighbors per exterior cell); cache exhausted (`!Useful`) candidates per sweep.
   - Move `ChargeSpots` cache invalidation to `map.events`, pre-expand the turbine buffer once per build, evaluate `UsableBy` lazily inside `Best()`'s BFS, and evaluate whether `Build` should continue past turbine-adjacent cells.
   - Remove per-tick LINQ allocations in `Building_Stable.Tick`, throttle `TickRebuild` material scans, move `EnsureSupplementals` past the fast-path return in `Tiers.Arm`, and deduplicate `StableFor` calls in `Retrieval`.
