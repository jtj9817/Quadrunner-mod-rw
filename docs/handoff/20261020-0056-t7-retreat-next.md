## Gotchas learned this session (add to TODO.md)

- **Vanilla defend-point raiders chase.** `LordJob_DefendPoint` defaults to a 28-cell defend radius and a flee toil; scenario raiders that hit a dog chased it home. `SpawnRaider` now passes `wanderRadius 2, defendRadius 3, addFleeToil false`.
- **Unarmed pirates die to Combatdog claws** rather than going down, so capture tests down their targets with `DownBleeding` (anesthetic) instead of relying on the fight.
- **A docked pawn's job reads "Carried"** (`JobGiver_Carried` from the Despawned think tree): not a bug when a summary shows it.
- **`Building_Stable.Targets` prunes the dead, destroyed, captured and off-map;** a dead pawn isn't found by `Scenario.ById` (its corpse has another ThingID), so `Fate` prints "gone" for the dead.
- **Ping order vs nearest first:** the first ping sends a docked Combatdog at once after that attacker; a nearer attacker pinged in the same tick is taken at the next re-sort (jobs expire every 60 ticks with `checkOverrideOnExpire`), not instantly.
